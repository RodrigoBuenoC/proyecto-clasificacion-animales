# 🐶🐔🐘 Animal Image Classifier

Aplicación de **Computer Vision e Inteligencia Artificial** capaz de analizar una imagen y clasificarla entre diferentes categorías de animales.

## 🚀 Demo

👉 **Prueba la aplicación en Hugging Face Spaces**

[Mi IA Animales](https://huggingface.co/spaces/rodirbc3/Mi_ia_animales)

La aplicación permite subir una imagen y obtener la predicción del modelo directamente desde una interfaz web desarrollada con **Gradio**.

## 🧠 ¿Qué hace el proyecto?

El usuario proporciona una imagen y el sistema:

1. Recibe la imagen.
2. La procesa para adaptarla al modelo.
3. Ejecuta la inferencia.
4. Obtiene la predicción.
5. Muestra el resultado al usuario.

El modelo está almacenado en formato **ONNX**, permitiendo realizar la inferencia de forma optimizada.

## 💻 Ejecución local

Clona el repositorio:

```bash
git clone https://github.com/RodrigoBuenoC/proyecto-clasificacion-animales.git
cd proyecto-clasificacion-animales
```

Instala las dependencias:

```bash
pip install -r requirements.txt
```

Ejecuta la aplicación:

```bash
python app.py
```
